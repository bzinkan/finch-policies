# Finch Policies

Static public policy pages for Finch.

Use these URLs in TikTok Developer Portal after deployment:

- `https://finch-policies.vercel.app/terms.html`
- `https://finch-policies.vercel.app/privacy.html`

## Deploy with Vercel

1. Open Vercel.
2. Click **Add New...** then **Project**.
3. Import the GitHub repo `bzinkan/finch-policies`.
4. Keep the framework preset as **Other** or **Static**.
5. Leave build command blank.
6. Leave output directory blank or set it to `.`.
7. Deploy.

If TikTok gives you a URL verification file, put that file in the project root, commit, push, and let Vercel redeploy.
