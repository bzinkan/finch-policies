Finch

Privacy Policy

Last updated July 9, 2026

This Privacy Policy explains how Finch handles information. Finch is a private desktop utility used by its operator to prepare and upload educational video content through official platform APIs.

1. Information Finch Uses

Finch may use local configuration values such as API client keys, client secrets, redirect URIs, selected scopes, and default posting preferences. After authorization, Finch may store access tokens, refresh tokens, token expiration values, and account identifiers returned by the platform.

2. Local Storage

Finch stores configuration and tokens locally on the operator's computer. It does not run a hosted backend, database, analytics service, advertising tracker, or third-party tracking script.

3. Platform Data

Finch may request creator account information, available privacy options, upload status, and posting-related metadata from official platform APIs when the operator runs CLI commands.

4. Video Content

Finch reads local video files selected by the operator and uploads them only when the operator runs an upload or posting command. Direct posting requires explicit confirmation before video bytes are sent.

5. Sharing

Finch does not sell personal information. Information is sent only to the platform APIs needed to authenticate, check account posting settings, upload drafts, or create posts as requested by the operator.

6. Security

API credentials and tokens should be kept private, excluded from source control, and rotated if exposed. The operator is responsible for securing the computer and local files where Finch runs.

7. Updates

This policy may be updated as Finch changes or as platform requirements evolve. The updated version will be posted on this page.
